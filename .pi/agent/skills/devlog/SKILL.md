# Devlog за сессию

Одна сессия — одна секция в дневном файле `~/Wiki/devlog/YYYY-MM-DD.md`. Запись — **журнал фактов**: то, что видно в разговоре и в репозитории. Рефлексию пишет пользователь.

## Шаги

1. **Спроси пользователя** одним сообщением:
   - «Во сколько начали сессию?» — если не видно из разговора;
   - «Что понял за сессию — своими словами, 1–3 предложения?»

   Ответ про понимание вставляй **дословно**. Пропустил вопрос — оставь в разделе `- [ ] дописать`.

2. **Собери факты:**
   - разговор: задача, что сделано, решения и почему, что не сработало;
   - репозитории, где в сессии менялись файлы (по истории разговора; если неясно — cwd): `git log --since="<начало сессии>" --oneline` и `git diff --stat`;
   - тесты из истории сессии: команда и итог; не запускались — так и пиши.

   Готово, когда у каждого пункта «Сделано» есть подтверждение: файл, коммит или вывод команды.

3. **Привяжи к неделе my_mmo:** `grep -l "статус: в работе" ~/Wiki/my_mmo/*.md`. Ссылка `[[…]]` — имя найденного файла без `.md`. Несколько заметок или ни одной — спроси. Сессия вне my_mmo — строку «Неделя» опусти.

4. **Покажи черновик** записи целиком и дождись «ок» или правок.

5. **Запиши.** Время — из `date -Iminutes`.
   - Файла нет — создай с frontmatter.
   - Файл есть — допиши секцию в конец. Из frontmatter меняй только `tags`: добавь `mmo`, если секция привязана к неделе. Остальное оставь как есть.

6. **Предложи отметить чекбоксы** в заметке недели, если сессия закрыла пункт. После согласия меняй в заметке только `- [ ]` → `- [x]` у закрытых пунктов; остальной текст и frontmatter оставь как есть.

## Формат

Новый файл:

```markdown
---
date: 2026-11-08T21:40+03:00
created: 2026-11-08T21:40+03:00
tags:
  - devlog
---
# Devlog 2026-11-08
```

Секция сессии:

```markdown
## 19:30 · <тема одной фразой> (~2,5 ч)

Неделя: [[Неделя 02 · Тик-сервер без сети]] · Репозиторий: `~/projects/my_mmo-server`

**Сделано**
- Тик-цикл на `time.Ticker`, 20 тиков/с — `server/tick.go` (abc1234)

**Решения**
- Фиксированный тик вместо дельты: детерминизм для повторов охоты.

**Не сработало**
- `select` с `default` в цикле — грузил CPU на 100 %.

**Тесты:** `go test -race ./...` — зелёные.

**Понял своими словами**
> <ответ пользователя дословно>

**Дальше:** <один конкретный следующий шаг>
```

Пустые разделы «Решения» и «Не сработало» опускай. «Дальше» обязателен — с него начинается следующая сессия.
